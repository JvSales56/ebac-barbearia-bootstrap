# Estilo Livre | Barbearia

Projeto desenvolvido durante o curso de Front-end da EBAC, com foco na criação de uma página web responsiva para uma barbearia fictícia.

O projeto foi desenvolvido utilizando **HTML5, Bootstrap e SCSS**, aplicando conceitos de responsividade, utilização do sistema de Grid do Bootstrap, componentes pré-construídos e organização modular dos estilos com SCSS.

## Tecnologias

- HTML5
- Bootstrap 5
- SCSS
- CSS3
- Bootstrap Grid System
- Flexbox
- CSS Grid
- Media Queries

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela
- Menu de navegação responsivo utilizando o Navbar do Bootstrap
- Banner principal (Home)
- Seção "Sobre Nós"
- Seção de serviços
- Cards de serviços utilizando componentes do Bootstrap
- Seção de depoimentos
- Carousel de depoimentos utilizando o Bootstrap
- Formulário de contato
- Utilização de classes utilitárias do Bootstrap
- Organização dos estilos utilizando SCSS
- Separação dos estilos em arquivos de base, componentes e seções
